# MotorMatch Logo Prompt

## Tentang Software
**MotorMatch** adalah software **Motor Selection & Sizing Tool** — aplikasi engineering untuk menghitung dan memilih motor listrik (servo, stepper, induksi) yang tepat berdasarkan parameter mekanisme (ball screw, conveyor, rack & pinion, dll).

## Prompt Utama

```
Minimalist logo design for "MotorMatch" — a motor selection and sizing software tool. Letter "M" seamlessly integrated with a mechanical gear/cogwheel icon, representing precision engineering and motor mechanics. Clean geometric lines, flat vector style, solid black on white background, modern tech branding, no gradients, no shadows, scalable icon, professional software logo, 4K
```

## Prompt Detail

```
Minimalist tech logo for "MotorMatch", an engineering software for motor sizing and selection. Bold uppercase letter "M" where the center peaks transform into a single mechanical gear cogwheel, symbolizing the match between motor and mechanism. Flat vector design, solid black, clean negative space, geometric precision, no gradients, no 3D effects, no textures, modern SaaS software branding, isolated on pure white background, scalable vector icon
```

## Negative Prompt

```
realistic, 3D render, gradient, shadow, texture, complex details, multiple colors, photorealistic, busy design, ornamental, decorative, photography, human hands, robot
```
